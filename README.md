# NL2SQL Knowledge Graph Lab

Lab environment for natural-language-to-SQL over curated datasets, with knowledge-graph oriented preparation workflows.

## Architecture

Data prep -> schema/context enrichment -> NL2SQL evaluation loops.

## Stack

Python (pandas, Postgres tooling), PowerShell

## Why this matters

Built as an Applied AI Architecture showcase: clear system boundaries, agent/tooling seams, and a path from prototype to operable demo.
